Outil de calage — emboîtement des Dashboards

Le command board reste FIXE en haut à gauche (l'ancre — "tout à gauche, zéro marge"). Pour chaque autre board (diceboard, small, medium, large), clique sur le plateau à l'endroit où doit tomber son COIN HAUT-GAUCHE pour caler grossièrement, affine avec les flèches (Maj+flèche = pas plus large) ou le pavé, puis valide (Entrée). Chaque board est dessiné à sa vraie taille et par-dessus les précédents (même ordre que dans le jeu), donc tu vois directement l'emboîtement se former. Une fois les 4 cibles validées, « Copier les réglages » remplace BOARD_LAYOUT dans tools/ui-script.js.

    L'ordre d'empilement (quel board est dessiné par-dessus lequel) est fixe : command, puis diceboard, puis small, medium, large. Si l'emboîtement demande l'ordre inverse à un endroit, dis-le — c'est un changement d'une ligne.

    Réglage fin

    Clique d'abord sur le plateau pour caler grossièrement ce board.
