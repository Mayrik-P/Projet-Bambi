Outil de calage — slots des Dashboards

Une cible à la fois (voir liste à droite). Clique directement sur la vraie image à l'endroit où doit tomber le slot indiqué. Le point se place immédiatement, la cible suivante s'active toute seule. Clique un élément de la liste pour revenir corriger un slot déjà placé. Une fois les 16 cibles posées, ajuste si besoin la taille des carrés avec les curseurs, puis clique « Copier les réglages » : le texte généré remplace directement VEHICLE_SLOT_FRACTION / COMMAND_SLOT_FRACTION / VEHICLE_SLOT_SIZE_FRACTION / COMMAND_SLOT_SIZE_FRACTION dans tools/ui-script.js.

    Taille des slots

    Fraction de la hauteur affichée du dashboard concerné — carré centré sur chaque point déjà posé.
